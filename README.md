# Predição de Resolução de Reclamações Bancárias

Projeto desenvolvido no contexto da disciplina de Mineração de Dados do PPCA/UnB.

## Objetivo

Desenvolver e avaliar modelos de classificação capazes de estimar a probabilidade de resolução de reclamações no setor bancário brasileiro.

## Estrutura

- `notebooks/`: notebooks utilizados nas etapas de preparação, modelagem e avaliação.
- `Base de dados/`: arquivos brutos e processados utilizados na pesquisa. Esta pasta não é versionada no GitHub.

## Base de dados

Os dados foram obtidos do Consumidor.gov.br e organizados em arquivos mensais.

Para preservar os dados e evitar o versionamento de arquivos volumosos, a pasta `Base de dados/` está incluída no `.gitignore`.
